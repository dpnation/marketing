applause-aeo-content-audit

Page-level term-alignment audit

Scores a specific page against the 60-term AEO keyword list across five weighted dimensions. Current quarterly instrument, built by Megan Ratcliff.

  • Term Alignment (primary/secondary/supporting terms)
  • Characterization accuracy
  • Extractability
  • Evidence
  • Attribution & Freshness
Produces → Term-alignment HTML scorecard
● Built
applause-aeo-technical-audit

Page-level technical audit

Checks a specific page for the technical fixes that make it crawlable and citable by AI search engines. No keyword scoring or content-quality review — a four-step action list for the web/dev team.

  • Schema markup
  • AI bot access (robots.txt)
  • Crawlability & rendering
  • Structural extractability
Produces → Technical AEO HTML report

Replaces the broader ai-seo-aeo instrument used for the Q3 2026 baseline (see Reports below).

Page Term Audit Report

Term-alignment scorecard

HTML report. Composite score + five dimension scores, term-by-term performance table, and priority fixes for the page's primary and secondary terms.

  • Composite score (0–100) and band
  • Term-by-term placement and score
  • Dimension breakdown
  • Priority fixes (P1/P2/P3)
Technical Page Audit Report

Technical fix list

HTML report for the web/dev team. Four-step technical action list — no copy or messaging recommendations.

  • Schema implementation checklist
  • Bot access verification
  • Crawlability & rendering fixes
  • Structural extractability gaps
LLM Visibility Report

Strategic content gap brief

HTML report. Where Applause is invisible, who owns those spaces and the specific content arguments that would close each gap.

  • 17% baseline citation rate (June 2026)
  • 4 complete blackout categories
  • Testlio cross-category competitive threat
  • 0% evaluative/investigative intent rate
  • 6 ranked content recommendations

How the Skills Connect

Run applause-aeo-visibility-audit first to identify which topics and pages need attention at the brand level. Then run applause-aeo-content-audit and applause-aeo-technical-audit on each priority page — one diagnoses the copy, the other diagnoses the plumbing — to get the full fix list.

Strategy sets the direction. The two page-level audits build the brief.
Content Audit Answers: does this page's copy earn its priority terms?
Technical Audit Answers: can AI crawlers even reach and parse this page?
Visibility Audit Answers: where are we invisible across AI platforms, and why?
