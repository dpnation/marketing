The Skills

What each skill does

Each skill has a single job. Run them in order — visibility audit first to set direction, then the content and technical audits together to build the full brief for each priority page.

📝
/applause-aeo-content-audit Term-alignment content audit
One URL in → one term-alignment scorecard out. Scores a specific Applause page against the 60-term AEO keyword list across five weighted dimensions — does this page earn the terms it's supposed to own?
● Built
What it scores
  • Term Alignment (primary/secondary/supporting terms)
  • Characterization accuracy (evidence-locked read)
  • Extractability (structure an AI engine can lift from)
  • Evidence (numbers, proof points, declarative claims)
  • Attribution & Freshness
Output
  • Composite score /100 and band (Strong/Adequate/Weak/Failing)
  • Term-by-term placement table
  • Standouts and misses
  • P1/P2/P3 fix list, ordered by effort
  • Handoff to geo-blog-optimizer for the rewrite
Produces → Term-alignment HTML scorecard
Trigger phrases
"audit this page against our keywords" "score this page for AI search" "which keywords does this page own" "run the AEO content audit on applause.com/[page]"
🔧
/applause-aeo-technical-audit Technical page audit
One URL in → one four-step HTML action list out, built for the web/dev team. Checks whether AI crawlers can actually reach, parse, and cite the page — no keyword or content-quality scoring.
● Built
What it checks
  • Schema markup (JSON-LD) — present/missing/invalid
  • AI bot access via robots.txt (GPTBot, ClaudeBot, PerplexityBot, etc.)
  • Crawlability & rendering (JS-gated content, noindex, canonical)
  • Structural extractability (headings, semantic markup, alt text)
Output
  • Pass / Fail / Needs Verification per check
  • Overall status pill: Ready / Needs Fixes / Blocked
  • One flat, prioritized fix list for engineering
  • Handoff to schema-markup for any JSON-LD gap
Produces → Technical AEO HTML report
Trigger phrases
"is this page crawlable by AI bots" "check this page's schema and robots.txt" "give the web team an action list for AI visibility" "run a technical AEO audit on this URL"

The Program

How the three skills connect

The skills are designed to run in sequence. Each one feeds the next.

Run the visibility audit first — it tells you which topics and pages Applause is invisible for and why. Use those findings to prioritize which pages need attention.

Then run the content audit and technical audit together on each priority page. The visibility report sets the strategy; the two page-level audits build the full implementation brief — one for the copy, one for the plumbing.

A shared QA evaluator for all three reports is planned but not yet built. Until then, review reports yourself before they go to a stakeholder or the web team.

Strategy sets the direction. The two page-level audits build the brief.
Content Audit Answers: does this page's copy earn its priority terms?
Technical Audit Answers: can AI crawlers reach and parse this page?
Visibility Audit Answers: where are we invisible across AI platforms, and why?
