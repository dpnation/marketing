Frequently Asked Questions

What's the difference between training data and test data?

Training data teaches the model by letting it repeatedly evaluate labeled inputs and outputs. Test data, applied only after training is complete, provides a final, unbiased check against unlabeled data the model has never seen.

What is validation data used for?

Validation data provides the model's first check against unseen data during training, letting a team tune hyperparameters and catch overfitting or underfitting before the model is finalized.

Is validation data the same as test data?

No, though some organizations use the terms interchangeably. Validation data tunes the model during training and is typically labeled for metrics; test data runs through the model as a black box afterward, typically unlabeled, to confirm it generalizes to new inputs.

What is LLM training data collection?

LLM training data collection is the process of sourcing the training, validation and test datasets — text, images, video, speech and more — that large language models and other ML algorithms need to learn, tune and prove they work correctly.
