What Is Regression Testing?

Just because functional tests pass once doesn't mean they'll always pass. When developers commit new code or change a feature, you run regression tests to make sure the software still functions as expected. Regression testing helps maintain a stable product while changes are made to it. Testers often automate types of functional testing such as these that have predictable outputs.

Example: A clothing retailer adds the ability to pay with customer rewards points on their mobile app. Testers might perform regression tests on other existing functionality, such as the ability to pay with credit cards and gift cards, to make sure all forms of payment work correctly.

What's the Difference Between Alpha and Beta Testing?

Alpha testing uses internal team members — people knowledgeable about the project but not directly involved in building or testing it — to catch major bugs before external users ever see the software. Beta testing comes next: a select group of real end users tries the product with no prior knowledge of it, surfacing feedback and edge-case bugs an internal team is less likely to find.

Example: A casino games provider assembles a cross-functional internal group to alpha-test a new video poker release. Once that group signs off, a restaurant chain's mobile order-and-pickup feature moves to beta testing with a small group of dedicated customers before a full rollout.

Frequently Asked Questions

What is functional testing?

Functional testing verifies that software works according to its specifications and in line with user expectations, using techniques like unit testing, integration testing and system testing to check behavior from a single function up to the complete system.

What are the most common types of functional testing?

Unit testing, component testing, smoke testing, sanity testing, regression testing, integration testing, API testing, UI testing, system testing, compatibility testing, white-box testing, black-box testing, exploratory testing, acceptance testing, alpha and beta testing, and production testing.

What's the difference between functional and non-functional testing?

Functional testing checks whether software does what it's supposed to do against stated requirements. Non-functional testing evaluates qualities like performance, security and usability that sit alongside functionality rather than replacing it — Applause's software testing programs combine both.

What's the difference between white-box and black-box testing?

White-box testing is performed with visibility into the software's internal code and design, typically by developers. Black-box testing validates expected outputs against inputs without visibility into the internal code, testing the software the way a customer would experience it.
